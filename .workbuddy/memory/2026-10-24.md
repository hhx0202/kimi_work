## 小卡日期带年 / 详情省高度 / 成就图去标题去连击框 / 修「按钮点不动」（本地 commit，未推送）

- **小卡日期带年**：`caughtDay()` 出 `2026-10-24`，时分拆成单独元素 `.mini-hm`（`caughtTime()`）。能不能显示时分交给 **CSS 容器查询**（`.pm-card-mini { container-type: inline-size }` + `@container (min-width: 112px)`）：3 列窄卡内容区只有 95px，`2026-10-24 00:40 100/300` 要 ~106px 放不下；2 列时内容区 122px 才塞得下。**时分一定单独一个元素**，拼在日期字符串里被 `overflow:hidden` 截断时会把时分吃掉半截，看不出是"宽度不够"还是"数据坏了"。字距用 `letter-spacing:-.45px`、字号 9px 才勉强排得下，`.mini-when` 的 gap 给 3px（给 1px 会显示成 `2026-10-2400:40`）。
- **详情省高度**：捕获时间 + `EXP 220/300` 并成一行 `.ptcg-meta`（flex 两端对齐）。**捕获时间原来 `color:#a0a4a8` 压在草绿/紫底上几乎看不见** → 改成自带半透明白底胶囊（`rgba(255,255,255,.78)` + `#37474f` 粗体），任何属性底色上都清楚。
- **介绍块和招式块不等宽**：`.ptcg-flavor` 原来是 `margin: 10px 14px 0`，比 `.ptcg-moves` 左右各多缩进 14px → 改 `margin: 10px 0 0`。两处「👆 点上面的名字…」（`.chain-tip`）已删。
- **成就图**：删掉顶部「🏝️ 佑佑的任务岛」+ `ADVENTURE LOG`，删掉「必做全清连击」框（剩两个框，宽度才跟卡片对得上），底部日期换成一句台词（`shareQuote` + `SHARE_TYPE_LINES` 按属性挑 + 通用池，`sharePick.quoteSeed` 播种，**不能用 Math.random**：预览和截图是两次独立渲染）。
- **「关闭 / 生成图片」点了没反应（真 bug，已修）**：`.share-card` 用 `transform: scale()` 缩进屏幕，但 `.share-scaler` 的**布局盒仍是 640×685**，溢出 `.share-fit` 正好盖住底部按钮；`.share-fit` 是 `position:relative`，画在静态的 `.share-acts` 之上 → 点击被透明盒子吃掉。修法：`.share-scaler { pointer-events: none }` + `.share-acts { position: relative; z-index: 6 }`。
  - **教训（很重要）**：脚本里 `el.click()` 是直接派发事件、**绕过命中测试**的，所以之前一直"验证通过"。判断这类"点了没反应"必须用 `Input.dispatchMouseEvent` 真点，或 `document.elementFromPoint()` 查那个坐标到底命中谁（修复前返回 `.share-scaler`，修复后返回按钮）。
